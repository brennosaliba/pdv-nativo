Roteiro de testes para automações comerciais
Versão: 20260819
Introdução
Este documento tem como objetivo definir uma sequência de testes a serem 
realizados para assegurar o correto funcionamento do sistema de automação
comercial integrado com a solução PayGo.
Público
Este documento destina-se a desenvolvedores responsáveis pela implementação 
do TEF PayGo.
Aviso
As informações contidas neste documento estão sujeitas a alteração.
Passo 01. Instalação
Procedimentos
Realize uma instalação com os dados enviados pela PayGo.
Resultado esperado
Instalação realizada com sucesso, recibo impresso.
Se a instalação do PdC ou client já foi realizada, não é necessário realizar novamente.
Verificar
● Mensagem para o operador: “TRANSAÇÃO APROVADA”;
● Recibo impresso corretamente;
● Transação confirmada para a automação comercial.
Observações
● Para a integração via Web Service (ControlPay), além de realizar a instalação, faça o login. Resultado 
esperado: Status 200 OK.
Teste válido para as integrações do tipo:
● Troca de arquivos TXT;
● Biblioteca Windows (DLL);
● Android;
● Pagamento via Web Service (ControlPay).
